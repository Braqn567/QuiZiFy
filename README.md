# Quizify

Quizify е приложение за по-лесно учене. Качваш документ или снимка от учебния си материал, а Gemini прави тест само от него. След решаването получаваш оценка, процент успеваемост и списък с теми, върху които да наблегнеш.

## Какво може

- тест от PDF, текстов файл, снимка или снимка с камерата
- въпроси с един верен отговор или с няколко верни (като на изпит)
- три нива на трудност и избор на брой въпроси
- оценяване "всичко или нищо" или частично, с точки според броя на верните отговори
- оценка по шестобалната система, време за решаване и успеваемост по теми
- профили с вход, снимка и био
- история на тестовете с графика на прогреса

## Технологии

- Python 3
- Streamlit за интерфейса
- Google Gemini API за генерирането на въпроси
- SQLite за потребителите и резултатите

## Структура

```
app.py          входна точка: меню и страници
ai.py           заявка към Gemini и обработка на въпросите
scoring.py      точки, оценка и обобщение по теми
database.py     SQLite: потребители, резултати, профил
ui.py           малки HTML компоненти и картата с резултата
views/          страниците: нов тест, история, профил
assets/         икона и стилове (style.css)
```

## Стартиране

```
pip install -r requirements.txt
streamlit run app.py
```

В основната папка трябва да има файл `.env` с ключ за Gemini:

```
GEMINI_API_KEY=твоят_ключ
```

Ключ се взима безплатно от Google AI Studio. Файловете `.env` и `quizify.db` не се качват в GitHub.
